# Meet with the Bishop

A one-page site for a ward executive secretary in The Church of Jesus Christ of Latter-day Saints. Members can see office hours, read about common appointments, and write a text message requesting a time.

## Customize

Open `index.html` and edit the `CONFIG` block near the bottom (name, ward, phone, email, office hours). The appointment types live in `TYPES` just below it.

This is a personal page, not an official Church website.
